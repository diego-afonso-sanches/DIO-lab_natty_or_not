# A Mata Atlântica

## 📒 Descrição
Um dos conteúdos estudados no componente de Ciências são os biomas, sendo que no estado de São Paulo possuímos dois biomas, Mata Atlântica e Cerrado. Desta forma, foi criado um vídeo sobre o bioma Mata Atlântica.

## 🤖 Tecnologias Utilizadas
Liste as IAs Generativas e outras ferramentas usadas
Foi utilizado o Google Flow (Nano Banana 2 Lite e Omni Flash) para a geração do vídeo. 

## 🧐 Processo de Criação
O vídeo foi criado a partir do prompt:  
´´
Suponha que você seja um professor de Ciências de uma turma de 6º ano. Ajuste a linguagem para o perfil selecionado, estudantes de 6º ano. Elabore um vídeo realista e curto sobre o bioma mata atlântica. Gere de forma gratuita o vídeo no formato mp4.
´´
